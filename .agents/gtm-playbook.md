## 1. What an expert actually thinks (no theater)

### Category
Not Otter / Fireflies / Fathom (notetakers).  
**Live AI presentation agent** — the bot *is* the presenter.

Closest true comps: presenter bots, digital SE / “protégé in Meet,” custom Recall + realtime voice demos — **not** meeting intelligence.

### Truth about “scale to $10M”
“$10M in a month” is a **late-stage outcome**, not a Week-1 KPI. Experts sequence proof → conversion → channel → scale:

| Stage | Winning looks like | Horizon |
|-------|--------------------|---------|
| **S0** | 10 live demos, 3 real quotes, demo path doesn’t break | Days 1–7 |
| **S1** | 50 demos / 20 activated / first paying | Days 8–30 |
| **S2** | Repeatable outbound + 1 launch spike (PH) + owned list | Days 31–60 |
| **S3** | One channel that prints meetings weekly | Days 61–90 |
| **S4** | Category ownership + sales motion that can hit serious MRR | Month 4–12 |

We optimize **S0 → S1 first**. Platforms amplify a working loop; they don’t create one.

### Growth spine
```
Proof clip → Demo offer → Live Meet → Quote / email → Outbound volume
                              ↓
              Soft directories → Product Hunt / paid experiments
```

**Primary motion = demo-led outbound.**  
**Platforms = rented attention.** Use after you convert strangers in &lt;15 minutes.

## 2. SLC gate — ship / don’t hide

DeckVoice is **Simple** (one job). Almost **Complete** for that job. It becomes **Lovable** when a stranger watches it present *their* deck.

### Must-fix before hard marketing (48–72h)
- [ ] Launch → session path works end-to-end (no dead nav)
- [ ] Kill fabricated testimonials / “100% / 3×” claims without proof
- [ ] Record 20–40s raw proof clip (join → slide → answer → abstain)
- [ ] One-page “how to demo” for yourself (upload → ready → launch → present)
- [ ] Booking path: Cal.com / Calendly **or** “reply with deck + Meet link”

### Domain
Buy as soon as practical (trust in DMs). **Do not block Day-1 outreach on domain.** Swap links when live.

### Explicitly NOT required before marketing
Calendar auto-join, CRM, Slack, SSO, team invites, escalate-to-human, multi-instance scale, SEO blog, ads at scale.

## 4. Positioning features — what to add, and when

Only ship features that sharpen the category or remove demo friction. Everything else waits for repeated buyer asks.

### Tier A — before / during Phase 0–1 (unblocks marketing)
| Change | Why it positions better |
|--------|-------------------------|
| Fix Launch → Session nav | Demo can’t die mid-flow |
| Honest site claims + real quotes only | Trust = conversion |
| Proof video on homepage + LinkedIn | Category clicks in &lt;30s |
| Booking CTA as primary | Matches how this product is bought |
| Custom domain | Looks like a company in DMs / PH |

### Tier B — before Product Hunt (Phase 2)
| Change | Why |
|--------|-----|
| Google OAuth | Less friction for founder/sales traffic spike |
| “Try on your deck” guided first-run (3 steps) | Strangers won’t learn the operator studio |
| Auto-open session after launch | Removes paste-session-ID energy |
| Presenter title: DeckVoice (not VoiceNav / Overtone) | Brand consistency on camera share |
| Pricing honesty: free vs paid differentiated | Starter = Free launches is a weak upsell; fix before PH |

### Tier C — only if demos demand it (Phase 4+)
| Change | Trigger |
|--------|---------|
| Calendar auto-join | 5+ buyers say “I won’t paste links forever” |
| Team invites / workspace UI | Selling to sales teams &gt; solo founders |
| Escalate-to-human tool | Enterprise / partner protégé deals |
| CRM notes / post-call summary | Only if buyers insist — don’t become Otter |
| Claim→source UI (“answered from slide 7”) | Killer trust UI after first 20 demos |

**Rule:** Same ask 3+ times in demos → then build. Not before.

## 7. Platform deep-dives

### Product Hunt
- **Purpose:** Badge, early adopters, social proof — not durable revenue alone.
- **Prep:** Aged maker profile; gallery; 45–60s video; tagline ≤60 chars; maker first comment; warm supporters.
- **Timing:** Tue–Thu, **12:01 AM PT**. First 4–6 hours set rank. AI category is crowded — win on *specific job* (“presents your deck live”).
- **Warm list target:** Prefer 200–400+ real notify/supporters before hard PH date ([2026 PH checklists](https://www.tooljunction.io/guides/product-hunt-launch-checklist-2026), [ShipNative PH AI guide](https://www.shipnative.dev/blog/how-to-launch-ai-built-app-on-product-hunt)).
- **Rule:** Launch only when you can answer every comment in &lt;30 min for 12+ hours and convert to email/demo. No bought upvotes.

### outbid.lol
- **What:** Public leaderboard — **rank = bid** (whole dollars, $2 min). Pay more → sit higher. ([rules](https://outbid.lol/rules), [site](https://outbid.lol/))
- **What you’re buying:** Short indie/tech eyeballs while culturally hot — **not** SEO authority, **not** a PH replacement.
- **Rule:** Optional test **$50–150**. Measure clicks → demo bookings. Stop if CPC garbage. Do not chase #1 ego (top bids have run into thousands).

### Alternatives to stagger
| Platform | Use |
|----------|-----|
| Microlaunch / Smol Launch / Uneed | Soft launches before PH |
| BetaList | Pre-PH waitlist |
| Indie Hackers | Story + feedback |
| SaaS directories | Permanent listing after domain |
| Peerlist / Launching Next | Extra indie visibility |
| founder.best-style boards | Community upvote alternatives to pay-to-rank |

---

### Phase 1 — Force traction (Days 4–14)
**Goal:** 20–40 outbound/day → demos → real quotes.

| Focus | Detail |
|-------|--------|
| Daily outbound | LinkedIn + email; 15-min live present offer |
| Content | 1 post/day: clip / founder story / demo lessons |
| Capture | Yes → calendar + email list |
| Product | Only fix what blocked yesterday’s demo |
| Optional | Small outbid.lol test **if** domain + clip live |

**Scoreboard daily:** outbound sent · replies · demos booked/done · quotes · signups

**Gate → Phase 2:** ≥10 demos + ≥3 quotes + email list (≥50 ideal, ≥20 min).

---

### Phase 2 — Warm launch prep (Days 15–28)
**Goal:** PH-ready without cold start.

| Workstream | Actions |
|------------|---------|
| PH assets | Icon, 5–7 gallery, 30–60s video, tagline, maker comment |
| Warm circle | Ask demo users to engage launch day (authentic only) |
| Soft boards | Microlaunch / BetaList / Uneed — practice converting |
| Landing | Load-test; UTMs; optional “Coming to PH” |
| Pricing | Differentiate free vs paid before traffic spike |
| Tier B features | OAuth + guided first-run if demos showed friction |

**Gate → Phase 3:** Assets ready + warm supporters + landing converts.

---

### Phase 3 — Product Hunt day (Tue–Thu in Days 21–35)
| Window (PT) | Action |
|-------------|--------|
| 12:01 AM | Go live |
| First 6h | Reply every comment; discussion &gt; upvote begging |
| Morning | LinkedIn + X (unique angles) |
| All day | Convert to demo/email |
| +48h | Follow up every serious signup/commenter |

**After:** Badge on site · recap with real numbers · **keep outbound**.

---

### Phase 4 — Compound (Days 36–90)
Pick **one** scale lever from what worked:
1. Founder outbound → VA/SDR on winning script  
2. Partner / protégé beachhead (higher ACV)  
3. SEO around “AI presenter for sales demos” (slow, owned)  
4. Paid only if demo→pay CAC known  

**Do not** run all four.
